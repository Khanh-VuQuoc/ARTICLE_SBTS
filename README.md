# ARTICLE\_SBTS — Deep Hedging of Rainbow Options via Schrödinger Bridge

> **Paper:** *Multivariate Schrödinger Bridge Path Generation for Deep Hedging of Rainbow Options under Proportional Transaction Costs*
> **Status:** Under review

---

## Overview

This repository contains the **complete reproducible pipeline** for the paper.  
We compare three path generators — GBM, Heston, and SBTS (Schrödinger Bridge Time Series) — as training environments for a deep hedging agent on **multi-asset rainbow options** (Basket Asian Call and Asian Worst-of Put) with proportional transaction costs `c = 0.001`.

```
yfinance 2005–2026
       │
       ├── 2005–2019 (calibration) ──► GBM    20,000 paths
       │                           ──► Heston 20,000 paths
       │                           ──► SBTS   20,000 paths
       │                                    │
       │                                    ▼  split 16k/2k/2k (seed=42)
       │                                360 checkpoints (training)
       │                                    │
       └── 2020–2025 (OOS)  ──► 3 historical periods
                                            │
                                            ▼
                                 t-tests · MCS · SDR · TRAF
```

## Checkpoints

The **360 model checkpoints** (`.pt` files, ~19 MB each for GBM, ~similar for Heston/SBTS) are **not stored in this git repository** due to size constraints.

They are available at:

> 📦 **Zenodo:** https://doi.org/10.5281/zenodo.20176723

Each checkpoint follows a 5-layer provenance scheme:
1. Model weights + optimizer state
2. Architecture & hyperparameters
3. Per-epoch training history (loss, LR, grad norms)
4. Evaluation artifacts (residuals, PnL arrays) with SHA-256 hashes
5. Environment snapshot (torch version, CUDA, GPU, git commit)

## Experimental Design

| Component | Details |
|---|---|
| **Assets** | AAPL (Tech), JPM (Financials), XOM (Energy) |
| **Calibration period** | 2005-01-01 → 2019-12-31 |
| **OOS periods** | COVID 2019–2020 · Post-COVID 2021–2022 · Recent 2023–2025 |
| **Options** | Basket Asian Call · Asian Worst-of Put |
| **Strike levels κ** | {0.90, 0.95, 1.00} |
| **Transaction cost** | c = 0.001 (proportional) |
| **Seeds** | 10 per configuration |
| **Total runs** | 360 (3 generators × 2 options × 3 strikes × 10 seeds) |
| **Network** | LSTM-style, 10→64→64→d, CVaR(α=0.95) loss |
| **Training** | Curriculum: Phase 1 MSE (500 epochs) → Phase 2 CVaR (1000 epochs) |

### Three-way fairness principle

All three generators observe **only** pre-2020 data for calibration. OOS evaluation uses the **same** 3 historical periods, the **same** network architecture, and the **same** hyperparameters — ensuring all comparisons are apples-to-apples.

## Statistical Evaluation

| Test | Details |
|---|---|
| **Paired t-test** | 216 pairwise tests (BH-adjusted at 5%) |
| **Model Confidence Set** | 18 MCS computations (α = 0.10), Bernardi & Catania (2018) |
| **Scoreboard** | Win/Tie/Loss across 6 cells per period pair |
| **SDR / TRAF / CPSR** | Stress degradation metrics |

---

## Key Results

- **Representative market (2023–2025):** SBTS is the **singleton MCS** across all 6 (option, strike) cells — paired t-tests reject equality in 6/6 cells vs GBM and Heston.
- **COVID stress (2019–2020):** Ranking **reverses** — SBTS exceeds parametric baselines by 60–147% in hedging-error std; all three generators retained in MCS at α = 0.10 in 5/6 cells due to elevated cross-seed variance.
- **Mechanism:** SBTS failure under stress is traced to the **absence of a jump component** in diffusion-only bridge generators.

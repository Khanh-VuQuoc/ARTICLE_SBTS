# Thesis result mapping

Every number in the thesis must be traceable to an artifact produced by
`notebooks/SBTS_CANONICAL_A100.ipynb`. This file is the index from thesis
objects to the files that generate them. The notebook writes a run-specific
copy of this index, filled in with the actual hashes, to
`<run_dir>/THESIS_RESULT_MAPPING.md` at the end of every run.

**Nothing below may be quoted as a locked thesis result until a `FULL` run
reports `publishable: true` in its manifest (Gate 6).** Older notebooks
(`article_data`, `article_gbm`, `article_heston_sbts`, `article_4_3period`) and
their outputs are reference material only.

## Provenance chain

```
frozen data
→ locked configuration
→ deterministic seed identity
→ generator artifact
→ training checkpoint
→ per-path evaluation
→ statistical procedure
→ table/figure
→ thesis claim
```
